# Legacy desktop builds

These are the Tkinter versions of the ACEest app that the course provided
(the same files used in Assignment 1). They are kept unchanged for reference;
nothing here is imported, linted, scanned or packaged.

Each Flask release in this repository is a port of one of them:

| Desktop build | Flask release | What it brought |
| --- | --- | --- |
| `Aceestver-1.0.py` | 1.0.0 | program catalogue, workout/diet charts, site figures |
| `Aceestver-1.1.py` | 1.1.0 | client profile form, calorie estimate, adherence |
| `Aceestver1.1.2.py` | 1.1.2 | client list, coach notes, CSV export, adherence chart |
| `Aceestver2.0.1.py` | 2.0.1 | SQLite persistence, load client, weekly progress |
| `Aceestver-2.1.2.py` | 2.1.2 | same code as 2.0.1 - the Flask side used it for bug fixes |
| `Aceestver-2.2.1.py` | 2.2.1 | weekly adherence chart |
| `Aceestver-2.2.4.py` | 2.2.4 | four programs, BMI/risk, goals, workouts, body metrics |
| `Aceestver-3.0.1.py` | 3.0.1 | same code as 2.2.4 - the Flask side used it for the API/platform release |
| `Aceestver-3.1.2.py` | 3.1.2 | login and roles, membership expiry, program generator, PDF report |
| `Aceestver-3.2.4.py` | 3.2.4 | membership status and billing, program templates |
